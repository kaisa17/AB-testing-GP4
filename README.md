# AB-testing-GP4
# Statistics in Data Analysis: A/B-тестирование и проверка статистических гипотез

## Описание проекта

Проект посвящён применению статистических методов в анализе данных и состоит из двух частей:

1. **A/B-тестирование лендинга образовательного продукта**
   Анализируется эксперимент, в котором пользователям показывали старую или новую версию посадочной страницы. Цель — проверить, повлияла ли новая версия лендинга на конверсию в регистрацию.

2. **Проверка гипотез на демографических данных Adult Census Income**
   Исследуется датасет с социально-демографическими характеристиками жителей США и бинарной меткой дохода: `>50K` или `<=50K` в год. Цель — выявить факторы, связанные с высоким доходом, и проверить содержательные статистические гипотезы.

Проект включает разведочный анализ данных, проверку качества эксперимента, выбор статистических критериев, оценку мощности теста, bootstrap-анализ и интерпретацию результатов с точки зрения бизнеса.

# Часть 1. A/B-тест лендинга

## Цель анализа

Проверить, показала ли новая версия лендинга статистически и практически значимый рост конверсии в регистрацию на курс по сравнению со старой версией страницы.

## Данные

Датасет A/B-теста содержит 294 478 наблюдений и 5 признаков:

* `user_id` — уникальный идентификатор пользователя;
* `timestamp` — время посещения страницы;
* `group` — группа эксперимента: `control` или `treatment`;
* `landing_page` — версия страницы: `old_page` или `new_page`;
* `converted` — бинарный признак конверсии в регистрацию.

По дизайну эксперимента:

* контрольная группа должна видеть `old_page`;
* экспериментальная группа должна видеть `new_page`.

## Предобработка и проверка качества эксперимента

В ходе анализа были выявлены нарушения в данных:

* часть пользователей из контрольной группы видела новую страницу;
* часть пользователей из экспериментальной группы видела старую страницу;
* были обнаружены дубликаты по `user_id`.

Так как несоответствие между `group` и `landing_page` нарушает дизайн эксперимента, такие строки были удалены. После очистки осталось 290 585 наблюдений:

| Группа    | Страница | Пользователи | Конверсии | Conversion Rate |
| --------- | -------: | -----------: | --------: | --------------: |
| control   | old_page |      145 274 |    17 489 |          12.04% |
| treatment | new_page |      145 311 |    17 264 |          11.88% |

Дополнительно были проведены проверки:

* симуляционный A/A-тест внутри контрольной и тестовой групп;
* проверка Sample Ratio Mismatch по дням;
* анализ распределения трафика по дням, часам и дням недели;
* анализ накопительной конверсии.

По результатам проверок:

* группы сбалансированы;
* SRM не обнаружен: 0 дней с нарушением из 23;
* распределение трафика по группам равномерное;
* накопленная конверсия стабилизируется примерно через 7–10 дней после старта эксперимента.

---

## Основная метрика

В качестве основной метрики выбрана конверсия:

```text
Conversion Rate = количество пользователей, совершивших целевое действие / общее количество пользователей
```

Также рассчитывались:

* абсолютная разница конверсий;
* относительное изменение конверсии;
* доверительный интервал разницы конверсий;
* мощность теста для разных MDE.

---

## Гипотезы

**H0:** новая версия лендинга не меняет конверсию по сравнению со старой.

**H1:** новая версия лендинга меняет конверсию по сравнению со старой.

Для проверки гипотез использовался **z-тест для двух пропорций**, так как целевая метрика является бинарной, а размер выборок достаточно большой.

---

## Результаты A/B-теста

| Метрика                   |   Значение |
| ------------------------- | ---------: |
| Conversion Rate control   |     12.04% |
| Conversion Rate treatment |     11.88% |
| Абсолютная разница        | -0.16 п.п. |
| Относительная разница     |     -1.31% |
| z-статистика              |     -1.312 |
| p-value                   |       0.19 |

Так как `p-value > 0.05`, статистически значимых различий между контрольной и экспериментальной группами не обнаружено.

Новая версия лендинга не показала значимого роста конверсии. Более того, наблюдаемая конверсия в тестовой группе оказалась немного ниже, однако это отличие может объясняться случайными колебаниями.

---

## Bootstrap-анализ

Для дополнительной проверки был проведён bootstrap на 5 000 итераций.

Результат:

```text
Средняя разница: -0.00159
95% доверительный интервал: [-0.00394; 0.00073]
```

Доверительный интервал включает 0, поэтому bootstrap подтверждает вывод z-теста: статистически значимого эффекта не обнаружено.

---

## Анализ мощности теста

Дополнительно была рассчитана мощность теста для разных минимально детектируемых эффектов.

|   MDE | Мощность |
| ----: | -------: |
| 1.00% |    0.167 |
| 1.31% |    0.255 |
| 2.00% |    0.510 |
| 3.00% |    0.844 |
| 5.00% |    0.999 |

Фактическая относительная разница составила около 1.31%, но при текущем размере выборки мощность теста для такого эффекта составляет только 25.5%. Это означает, что эксперимент был недостаточно чувствителен для надёжного обнаружения настолько малого эффекта.

Для достижения мощности 80% потребовалось бы:

|   MDE | Размер выборки на группу | Примерная длительность |
| ----: | -----------------------: | ---------------------: |
| 1.00% |                1 151 917 |                182 дня |
| 1.31% |                  672 133 |               106 дней |
| 2.00% |                  289 213 |                46 дней |
| 3.00% |                  129 087 |                20 дней |
| 5.00% |                   46 864 |                 7 дней |

---

## Выводы по A/B-тесту

* Новая версия лендинга не показала статистически значимого улучшения конверсии.
* Оснований для раскатки новой версии на весь трафик нет.
* В данных были обнаружены нарушения соответствия между экспериментальной группой и показанной страницей, поэтому перед следующими тестами нужно проверить логику сплитования и трекинга.
* Тест был чувствителен к эффектам от 3–5%, но не был достаточно мощным для обнаружения эффекта около 1.31%.
* Для следующего эксперимента рекомендуется заранее зафиксировать MDE, рассчитать нужный размер выборки и длительность теста.
* Минимальная длительность теста должна покрывать полный недельный цикл, так как трафик имеет недельную сезонность.

# Часть 2. Проверка гипотез на Adult Census Income

## Цель анализа

Исследовать социально-демографические факторы, связанные с уровнем дохода, и проверить несколько статистических гипотез на основе EDA.

## Данные

Используется датасет **Adult Census Income** из UCI Machine Learning Repository.

В анализе используются признаки:

* возраст;
* тип занятости;
* образование;
* семейный статус;
* профессия;
* пол;
* раса;
* прирост капитала;
* потери капитала;
* количество рабочих часов в неделю;
* страна происхождения;
* уровень дохода.

Целевая переменная:

```text
income: >50K или <=50K
```

После удаления пропусков в данных осталось 30 162 наблюдения.

---

## EDA

В ходе разведочного анализа были выявлены следующие закономерности:

* датасет несбалансирован: большинство людей имеют доход `<=50K`;
* мужчины значительно чаще зарабатывают `>50K`, чем женщины;
* разрыв по доходу между мужчинами и женщинами сохраняется на разных уровнях образования;
* самозанятые с зарегистрированной компанией имеют самую высокую долю дохода `>50K`;
* семейный статус связан с уровнем дохода;
* люди с доходом `>50K` в среднем работают больше часов в неделю;
* наличие `capital_gain > 0` сильно связано с более высокой вероятностью дохода `>50K`;
* возраст достижения высокого дохода различается между уровнями образования.

---

## Проверенные гипотезы

### Гипотеза 1. Гендерный разрыв сохраняется даже при высшем образовании

**H0:** среди людей с высшим образованием доля дохода `>50K` одинакова у мужчин и женщин.
**H1:** среди людей с высшим образованием мужчины чаще имеют доход `>50K`.

Использовался z-тест для двух пропорций.

Результаты:

| Группа                        |     n | Доля `>50K` |
| ----------------------------- | ----: | ----------: |
| Мужчины с высшим образованием | 5 389 |       58.5% |
| Женщины с высшим образованием | 2 199 |       26.4% |

```text
Z-статистика = 25.3563
p-value = 3.83e-142
```

**Вывод:** нулевая гипотеза отвергается. Среди людей с высшим образованием мужчины статистически значимо чаще имеют доход `>50K`.

---

### Гипотеза 2. Семейный статус объясняет гендерный разрыв в доходах

**H0:** внутри каждой группы семейного статуса доля дохода `>50K` одинакова у мужчин и женщин.
**H1:** мужчины чаще имеют доход `>50K` независимо от семейного статуса.

Использовались:

* z-тесты для пропорций по группам семейного статуса;
* поправка Бонферрони;
* хи-квадрат тест для проверки согласованности результатов.

**Вывод:** семейный статус влияет на доход, но не полностью объясняет гендерный разрыв. В большинстве групп мужчины статистически значимо чаще имеют доход `>50K`. Исключение — группа людей в браке, где различия оказались незначимыми.

---

### Гипотеза 3. Самозанятые зарабатывают больше, чем наёмные работники

**H0:** доля людей с доходом `>50K` одинакова среди самозанятых с собственным бизнесом и наёмных работников.
**H1:** самозанятые с собственным бизнесом чаще имеют доход `>50K`.

Использовался t-тест Уэлча для двух независимых выборок.

Результаты:

| Группа       |      n | Доля `>50K` |
| ------------ | -----: | ----------: |
| Self-emp-inc |  1 074 |      55.87% |
| Private      | 22 286 |      21.88% |

```text
p-value = 1.96e-90
```

**Вывод:** нулевая гипотеза отвергается. Самозанятые с собственным бизнесом статистически значимо чаще имеют доход `>50K`, чем наёмные работники.

---

### Гипотеза 4. Возраст достижения высокого дохода зависит от уровня образования

**H0:** средний возраст людей с доходом `>50K` одинаков для разных уровней образования.
**H1:** хотя бы одна образовательная группа отличается по среднему возрасту.

Использовался Welch ANOVA, так как дисперсии между группами различаются.

Результаты по среднему возрасту среди людей с доходом `>50K`:

| Образование  |     n | Средний возраст |
| ------------ | ----: | --------------: |
| HS-grad      | 1 617 |            44.7 |
| Some-college | 1 336 |            43.9 |
| Bachelors    | 2 126 |            42.4 |
| Masters      |   918 |            45.2 |
| Doctorate    |   280 |            48.1 |

```text
p-value = 6.49e-23
```

**Вывод:** нулевая гипотеза отвергается. Возраст достижения высокого дохода статистически значимо различается между уровнями образования.

# Итоговые выводы

## По A/B-тесту

Новая версия лендинга не дала статистически значимого роста конверсии. На текущих данных её нельзя рекомендовать к внедрению. При этом эксперимент был недостаточно мощным для обнаружения небольшого эффекта около 1.31%, поэтому для будущих тестов важно заранее фиксировать MDE и рассчитывать размер выборки.

## По Adult Census Income

На уровень дохода заметно связаны следующие факторы:

* пол;
* образование;
* семейный статус;
* тип занятости;
* количество рабочих часов;
* наличие прироста капитала;
* возраст.

Статистические тесты подтвердили, что:

* гендерный разрыв в доходах сохраняется даже среди людей с высшим образованием;
* семейный статус влияет на доход, но не полностью объясняет разницу между мужчинами и женщинами;
* самозанятые с собственным бизнесом чаще имеют доход `>50K`;
* возраст достижения высокого дохода зависит от уровня образования.
